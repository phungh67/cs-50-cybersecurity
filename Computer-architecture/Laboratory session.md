
# Anatomy of a computer architecture lab

Since designing a whole new concept of processor or computer system architect will bring a bomb to the "professional world", a master student can only try to run the benchmark (with a set of pre-defined test cases) to understand (or to get a glimpse) of how cache, instruction queue, ... do in real life.

Provide two things:
- A configuration file: which defines the model of processor, the architect of cache, and vice versa.
- A test (benchmark) file: which includes several test cases - all packed with intensive command depends on the aspect (mobile, multimedia or algorithm).
