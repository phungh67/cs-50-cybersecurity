
# Systems - The basic concept

The one encapsulates entities to create a basic foundation and a limited context for the game to be played. 
It is also considered as a state machine with initial, end and goal state. The end defines the state that other players can achieve regardless of how many advantages, scores, resources they acquired during the game. 
Inside the system, we also have events or rules, that could be changed, updated to restrict what could be / could not be done by the participants. 
Emergent systems generate unpredictable patterns of complexity, because rules are not like what we know. And it can bring the second effect to the game play.

With the current evolution of the computer system, game can be viewed as a cybernetic system. The sensors act as input handlers, while logical comparator acts like the judges.4

# Design language
Purpose and use:
- Allows designers to embed meanings into artifacts.
- Allows these artifacts to express meaning to  other people.
- Basically allows the flow from designers to customers.
Components:
- Everything entities (mostly objects maybe) can be used, arranged, manipulated in a game.
- Must (should) have qualify rule for using it (when/how/which case these objects can be used).
