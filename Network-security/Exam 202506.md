>[! Question]
>What alternative(s) are correct regarding WEP?

- Encryption key is never changed during a session (only WPA family applies this, and even WPA still has flaw about this).

- Does not support cerftificate authentication in Enterprise mode.

>[! Question]
>What is correct for WPA2?

- WPA2 only encrypts session between the station (user) and Access Point.
- Individual sessions key are derived from the master key. They are unique for each station even if all stations share the same pre-shared key for authentication.
- Both sides participate in the generation of the pairwise transitent key since both nonces and MAC addresses are used.

>What is correct for WPA3?

- Released years ago but still not commonly used as now.
- Traffic is encrypted also in open network.
- Diffile Hellman is used to generate key even when shared password.

- Change cipher is used (still) in version 1.3 but can be skipped (since change cipher is default action).
