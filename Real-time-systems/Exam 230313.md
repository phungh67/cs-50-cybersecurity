Dhall's effect in the context of global multiprocessor scheduling refers to the following phenomenon: 
- If a traditional single-processor priority-assignment approach, such as RM, is used with global scheduling it is possible to construct a task set, that is not schedulable though it has a very low utilization, regardless of how many of processors are used

-> The reason behind this is: with the RM - rate monotonic priority, shorter task (light task, task with short period) will have higher priority than the heavy task (task have longer period). Also, the light task that maybe requires less resources, resulted in low utilization of the processor, but since the schedule is RM, they will always get slot to be executed first. Because of that reason, the heavy tasks eventually miss their deadlines - although the global utilization is still low, resource are still available, but because they have so lower priority -> miss deadline -> unschedulable.
