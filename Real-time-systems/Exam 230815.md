Consider the program below on C:
```C
int FuncY(int y){
	int t;
	if (y == 0){
		t = 0;
	} else {
		if (y == 1){
			t = 1;
		} else {
			t = y + FuncY(y-1);
			t = t * t;
		}
	}
	return t;
}
```

Assume the following costs for the language statements:
- Each declaration and assignment statement costs 1 to execute.
- Each function call costs 2 and the wort execution time estimation of the function also.
- Each evaluation of the logical condition, either for if or while costs 2.
- Each add and subtract operation costs 3.
- Each multiply operation costs 5.
- Return statement costs 2.
- Other language statements can be assume 0 cost.

Worst time execution in the case $y=0$

- Evaluation y - costs 2
- Assign t - costs 1
- Return costs 2
Total: 6
